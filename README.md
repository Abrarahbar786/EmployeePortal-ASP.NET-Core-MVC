# Employee Portal – ASP.NET Core MVC

Employee Portal is a web-based Employee Management System developed using ASP.NET Core MVC, C#, Entity Framework Core, and SQL Server.

The application allows administrators to manage employee information through a simple and user-friendly interface.

## Features

- Employee CRUD operations
- Add new employees
- Update employee information
- Delete employees
- View employee details
- Employee search
- Department filtering
- Employee type filtering
- Pagination
- Department and designation management
- Admin profile
- Login and logout functionality
- Form validation
- Responsive user interface

## Technologies Used

- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQL Server
- HTML5
- CSS3
- JavaScript
- Bootstrap

## Project Structure

The project follows the ASP.NET Core MVC architecture.

- **Models** – Contains application data models.
- **Views** – Contains Razor views and user interface pages.
- **Controllers** – Handles application requests and business flow.
- **Services** – Contains application/business logic.
- **ViewModels** – Used to transfer and validate data between controllers and views.
- **wwwroot** – Contains static files such as CSS, JavaScript, and images.

## Search, Filtering and Pagination

The Employee Portal provides useful features for managing a large number of employees.

### Search

Users can search employees using employee information such as name or other available details.

### Filtering

Employees can be filtered based on:

- Department
- Employee Type

### Pagination

Employee records are displayed using pagination to make the employee list easier to manage and navigate.

## Database

The application uses SQL Server as the database.

Main database features include:

- Employee information storage
- Department management
- Designation management
- Employee type management
- CRUD operations using Entity Framework Core

## Login and Logout

The application provides a simple login and logout flow for administrators.

- Admin login
- Admin profile page
- Logout option
- Employee management access

## Validation

The application includes validation to ensure correct and complete employee information.

- Required field validation
- Email validation
- Date validation
- Employee information validation
- Server-side validation

## How to Run

1. Clone the repository.
2. Open the project in Visual Studio.
3. Restore the required NuGet packages.
4. Configure the SQL Server database connection.
5. Create or update the database using Entity Framework Core.
6. Build the project.
7. Run the application using Visual Studio.
8. Open the application in the browser.
